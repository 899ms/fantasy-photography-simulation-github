# fantasy-photography-simulation

Codex skill for generating AI photography collage image sets with Hasselblad, Leica, or Ricoh GR aesthetics.

## Contents

- `fantasy-photography-simulation/` - installable Codex skill folder
- `fantasy-photography-simulation-skill-20260715.zip` - packaged skill archive

## Install

Copy `fantasy-photography-simulation/` into your Codex skills directory, or unzip the packaged archive into that directory.
